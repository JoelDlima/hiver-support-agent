## Context
Three heads: T1 intent (11 classes, short noisy tweets), T2 grounded reply, T3 escalation
(binary + rationale, machine-readable). Constraint: CPU-only, cheap, repro <15 min,
no large GPU. Default pipeline must run keyless; LLM is gated/optional, never required.

## Candidates
Templates (deterministic, keyless) | gpt-4o-mini API (json_schema/strict) |
claude-haiku-4-5 API (premium alt / quality ceiling) | Llama-3.1-8B / Mistral-7B /
Gemma-2-2B-9B self-host | frontier-large (GPT-4o, Sonnet/Opus, Llama-70B)

## Decision
**Templates as default (v1 serving path — keyless, brand-consistent, zero hallucination
surface). gpt-4o-mini `json_schema/strict:true` as GATED Phase-2 drafter behind Pydantic
contract + ≤2 retries + template fallback, capped max_tokens + cached KB prefix.
Haiku-4-5 as quality-ceiling eval run only (promote iff blind human/A-B delta >
retry-adjusted cost delta).**

## Rejected — why
- Frontier-large per-request: 5–50× cost/latency + GPU/ops for single-digit-point gains
  on 11 short-text intents (ESTIMATE direction from MTEB + TweetEval domain-gap evidence).
  Encoder + small-LLM splits at the natural seam instead.
- Llama/Mistral/Gemma self-host as default: no vendor structured-output SLA (hand-rolled
  validation/retry), quant/CPU latency 0.5–3 s ESTIMATE, gated licenses (Llama/Gemma),
  breaks <15-min repro. Kept as offline/contingency track only (templates → quant 1–3B).
- Haiku-4-5 as default: 4–8× cost for tone/instruction-fidelity gain not yet proven on
  our eval; justified only as ceiling measurement.

## Cost / complexity / failure / scale
- Cost: templates $0 marginal. Mini path VERIFIED $0.15/$0.60 → ~$45/mo per 100k reqs at
  1k-in/0.5k-out; optional polish on <5% escalated traffic adds <$25/mo at 10k users
  (production.md §5). Batch −50%, caching −50–90% available.
- Complexity: one bounded LLM call max; schema ≤2 levels, `additionalProperties:false`,
  all-required + nullable optionals, `parallel_tool_calls:false`; app-side jsonschema
  validation → 1 repair retry → template fallback.
- Failure: refusal/truncation/filter voids guarantee → fallback; LLM confidence
  uncalibrated → combine with encoder margin + rule triggers; safety lexicon + injection
  rules escalate regardless of LLM output; never emit free-form steps (e.g. DFU/restore)
  unless in KB (top-1 score < τ → safe template + escalate=true).
- Scale: stateless single call; no loop → fixed token budget; Batch API for eval loads.
