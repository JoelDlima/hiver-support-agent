## Top-3 upgrades (effort S/M/L; none adopted — triggers gated)

Trigger: adopt on next index rebuild; verify recall@3 + p50/p95 parity vs current 7.1ms before switching serving path.
2. **MiniLM-L6-v2 cross-encoder rerank top-20 -> top-5 (S/M).** Keep cheap first-stage (TF-IDF/BM25S top-20/50), rerank to top-5 for prompt; CPU-budgeted (~tens of ms at K=20), 23M Apache-2.0, truncate 256 tok. Trigger: run only if failure analysis shows retrieved-but-low-ranked misses (F-suite); else stay k=5 NN.
3. **Intent robustness bundle (M): SetFit + Snorkel-denoise + balanced weights + temporal eval.** Fit Snorkel LabelModel over existing keyword LFs (coverage/overlap/conflict report) -> train SetFit MiniLM 8-20 shot on mined confusion pairs with class_weight=balanced + per-intent calibrated thresholds; add Oct-train/Nov-test temporal split + fasttext-ftz langID + BERTweet-soft norm (keeps brand/emoji). Trigger: human-200 intent acc <0.70 after label cleanup; French/non-English slice decides ftz+mE5-small need.

## What was NOT adopted (and why)

- FAISS/hnswlib/usearch ANN: exact NN already p50 7.1ms at 27k; ANN pays recall/build cost for zero need (Decision 001 stands).
- Dense embeddings (mE5) + RRF hybrid: no dense leg exists; RRF recipe recorded for Phase-2 only.
- Live X API / academic track: static TWCS dump + HF mirrors suffice; pay-per-use + 7-day + Enterprise wall make live collection cost/cap-negative.
- langdetect: dominated on acc + 10-80x speed; fasttext-ftz only.
- SMOTE: hurts tree/weighted models; balanced weights + threshold tuning first, resample inside folds only if minority <100-200.
