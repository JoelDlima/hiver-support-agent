## Pattern: what 90% do (the generic wrapper trap)
1. **Generic LLM wrapper or bare RAG (7/9):** seq2seq generation with no grounding (ldulcic), classifier-only with no reply (Vishesh062, eve-bot), or FAISS k=2–3 → GPT with no guard/gate (X-CustomerSupport, amine-akrout) or guard-NAMED but numberless (adityanaranje). Only `resolver` + `octavian115` enforce control-flow-in-code (routing/escalation in Python, not in the prompt).
2. **Generic intents, never brand-derived (7/9):** billing/technical/general or faq/billing/off-topic. Only `eve-bot` derives AppleSupport-specific intents — and it never ships them as an evaluated classifier. NOBODY publishes an 11-class AppleSupport taxonomy with per-intent P/R/F1 + confusion matrix.
3. **Keyword golden or no golden (9/9):** the two largest "goldens" are keyword pseudo-labels (Vishesh062 307k, eve-bot clusters). Demo `eval_dataset.json`s are un-sized, un-versioned, single-annotator at best. NOBODY reports a 200-item stratified HAND golden with dual-annotation + κ.
4. **Accuracy-only, no baselines that can lose (8/9):** single headline (99.5%, 68%, 93%) with no trivial-majority + keyword+BM25 floors. Only Vishesh062 shows a baseline table — and both arms share the SAME keyword labels (circular by construction, honestly admitted).
5. **No judge, and when judge then no agreement (9/9 support bots):** agent repos name-drop "hallucination rate / grounding guard / LLM-judge" with zero κ, zero swap/verbosity probes, zero CIs. The ONLY κ-bearing repos found are the judge-calibration family — which nobody in support-bot land imports.
6. **No failure suite, no misleading section (8.5/9):** octavian115's resilience table and resolver's edge log are the ceiling; neither asks "which headline number lies and why." Nobody publishes weak-vs-human κ, escalation 2×2, or per-intent collapse (e.g. OOS recall).
7. **No latency/cost (7/9):** one retrieval-latency point (<0.05s), one dashboard promise (p95/cost tracked, numbers n/s), one train-time/size footnote. Nobody reports p50/p95 end-to-end + $/1k-req alongside quality.

## Gaps we exploit (Hiver differentiation — map to our artifacts)
1. **Hand golden-200 + weak-vs-human honesty** → `evaluation/golden_human_200.csv` (200: 60 blind-manual + 140 assisted; 39 flips on first 60) + weak-vs-human κ=0.465 published as the CEILING. Nobody else quantifies their keyword-label ceiling.
2. **Baselines that can beat us** → trivial-majority + simple keyword+BM25 + final TFIDF-LogReg+NN+template+rules on BOTH weak-200 AND human-60 (simple wins intent 0.517 on human-60; final wins escalation 0.471 F1 + groundedness).Nobody else lets the cheap baseline win in public.
3. **Misleading-number section as a feature** → README "What is misleading" + FINAL_REPORT §16–18 (simple 1.000 = circular; final 0.795 optimistic; trust human-60 + escalation + groundedness). Only Vishesh062's label caveat comes close, without the numbers.
4. **Judge WITH agreement, gated** → `run_judge_agreement.py` (safety 0.909, esc-F1 0.582) + JUDGE_AGREEMENT_V2.md + 75-pair blinded protocol (2 humans + judge, κ/α/EM/swap/verbosity/z). Import the judge-family pattern (judgegate κ≥0.60 gate + judge-harness position-flip + judgeshift abstention/coverage) into support-bot eval — nobody else does.
5. **Escalation as calibrated decision, not sentiment-if** → 4-trigger rules + reason codes + 2×2 table + recall≥0.90 gate + handoff packet (intent+confidence+passage IDs+next step). Competitors escalate on angry-sentiment or low-confidence alone; nobody reports esc-P/R/F1 on hand labels.
6. **Groundedness with abstention + span ambition** → template-over-Apple-KB replies + cite-or-flag contract + F3/E15 abstention path; heuristic groundedness disclosed as circular-by-design (4.72/1.000 weak) with span-attribution + NLI gate queued. RAG demos stop at "retrieved top-k, generated fluent."
7. **Latency/cost next to quality** → TF-IDF NN p50 ~35ms + end-to-end p50 180ms/p95 192ms + $0 marginal/req local vs gpt-4o-mini ESTIMATE band in COST.md. Nobody else co-reports p50/p95 + cost with the quality table.
8. **Deterministic pipeline thesis vs agent-everything** → validate→classify→retrieve→draft→escalate→validate in plain Python+Pydantic (no LangGraph/LangSmith/Pinecone/OpenAI dependency; repro <15min CPU). Agent repos buy observability + vendor lock; we buy auditability + $0 + testability, and document the revisit criteria.
